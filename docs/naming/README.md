# How coSlash got its name

The naming work that produced this product's name, carried over from the
Fleetlog checkout before it was retired. It is the only copy.

This is history, not policy. Nothing here constrains what anything is called
today — it records how the decision was reached, which is the part that cannot
be reconstructed later.

| Path | What it is |
| --- | --- |
| `evaluations/` | One evaluation per candidate name — `coslash.md`, `slashpilot.md`, `logslash.md`, `metaslash.md`, `orch.md`, `histora.md`, and eleven more — plus `SUMMARY.md` comparing them. |
| `discussion.md` | The long-form exploration the candidates came out of. |
| `availability-verified.md` | Domain, npm, and handle availability checks for the shortlist. |
| `evaluation-template.md` | The rubric each candidate was scored against. |

The candidate list is worth keeping for a reason beyond sentiment: several
rejected names are close enough to the chosen one that someone proposing a
rename later would otherwise redo this work without knowing it had been done.
